# Radio Rocky Beach

Ein kleiner Webplayer für GTA-Radiosender. Reines HTML, CSS und JavaScript, ohne Framework und ohne Build-Schritt.
(Das Ganze ist ein AI Replica von einem Projekt das ich selber gecodet habe um VUE TypeScript und ein SDX kit zu lernen)
